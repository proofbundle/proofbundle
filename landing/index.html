What it does

  • Seals any artifact

    A signature over a Merkle-committed digest, with RFC 6962 domain separation. Nine digest algorithms, ten signature schemes, including post-quantum (ML-DSA, Falcon, SLH-DSA).

  • Anchors to independent time

    OpenTimestamps proofs and RFC 3161 timestamp requests, both built locally. Submitting them is the only step that touches the network.

  • Returns a named verdict

    Verification does not return a guess or a score. It returns one of a fixed set of outcomes, each with a reason.

  • Marks transparency for the EU AI Act

    Article 50 machine-readable marking, plus ready-made rule sets for regulated sectors expressed as plain-language requirements.

Scope

  • Provenance and safety are different questions. This answers provenance: what was sealed, when, by whom, unaltered since. It does not evaluate whether the underlying system is safe, unbiased, or fit for purpose.

  • Article 50 marking is machine-readable by construction — that's a fact about the artifact, checkable by anyone. Conformity assessment under the Act is a notified body's determination, not a software output; no tool from any vendor produces that determination by itself.

  • It does not inspect what you give it. A corrupted input is sealed faithfully as a corrupted input.

  • Temporal checks trust the local clock unless you anchor them. Every defect found so far is in the audit log.
