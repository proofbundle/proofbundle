Inspectable implementation

A result needs its basis.

Scratch implementations are embedded in the application and linked to their source files. Test receipts identify the vectors, implementation hashes, and observed results.

Published-vector conformance, browser diagnostics, and formal model theorems establish different facts. Implementation-refinement and timing proofs remain open. Passing FIPS-derived vectors is not FIPS module certification.
