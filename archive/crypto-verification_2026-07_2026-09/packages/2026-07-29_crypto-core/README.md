# ProofBundle Crypto Core Evidence Package 2026-07-29

This package preserves the uploaded crypto core zip, extracted source, generated cross-formal backfill files, addition MJS adapters/registry, Node test logs, manifest hashes, Merkle root, and a ProofBundle-style AIBOM signed with an included Ed25519 keypair.

Formal files are generated first-principles specification scaffolds. They are organized for Rocq/Coq 8.18, Lean 4, Isabelle/HOL, SMT-LIB/Z3, and HOL-family review. They are not represented as final closed certificates until checker logs are produced and published.

Node verification results are in verification_logs/.
