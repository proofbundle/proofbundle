High-risk obligations are in force now. Article 12 requires automatic recording of events across a system's lifetime. Article 19 requires providers to retain those logs. Article 50 requires marking AI-generated content. Retention is solved everywhere. Integrity is solved nowhere — a log the operator can rewrite is not evidence.

Agent actions, not just artifacts

The hard part isn't sealing a file. It's proving what an autonomous system did at 3am while nobody was watching.

Sealed at execution

Each action is canonically encoded, digested and Ed25519-signed the moment it runs — not batched afterwards, when it could be curated.

Hash-chained

Every entry commits to its predecessor. Remove or alter one and every entry after it breaks. Append-only, by construction.

Anchored to Bitcoin

Batches are Merkle-rooted and timestamped via OpenTimestamps. "Existed before block N" becomes a fact about the chain, not a claim about you.

Attributable

Agents carry cryptographic identity — PB-AI-BOM-1, SHA3-384, ML-KEM-768. Actions attach to a named agent and model, not to "the system".

Found in production, by the system itself

Every one of these came out of a live multi-agent forensic investigation — not a whitepaper.

  • ✓ Hooks correctly configured and silently not firing. ~30 agent actions executed entirely outside the chain, no error, no gap indicator. A provenance layer with an off switch is not a provenance layer.
  • ✓ Chain forked by concurrent writers. Four agents raced an append with no atomicity; two entries claimed one sequence number. Root-caused, locked, reconciled by appending — never by rewriting.
  • ✓ 11,640 agent actions never sealed at all. Five separate agent harnesses on one host, none of them in any chain, including the ones under investigation.

What it does not solve. Sealing witnesses execution, not observation. A model can read a secret in a tool result, hold it in context, never emit it, and leave no trace in any action log — while that value has already reached the inference provider. ProofBundle bounds this by sealing the context payload rather than only the tool envelope. No vendor currently does this at all. We say what it does and no more.
